# Vehicle Management System

Учебный проект на Java с абстрактным классом транспорта и классами автомобиля, мотоцикла и грузовика.

## Запуск

Требуется Java 11 или новее. В корне проекта:

```sh
javac src/*.java
java -cp src Main
```

Конструкторы проверяют обязательные названия, тип топлива, год и числовые характеристики транспорта.
